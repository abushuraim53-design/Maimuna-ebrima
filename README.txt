MAIMUNA & EBRIMA WEBSITE

WHAT'S INCLUDED
- A responsive website for Android phones and computers.
- A personal letter, photo section, daily reflection questions, future hopes, and a date countdown.
- Installable PWA support for browsers that support "Add to Home screen".

ADD MAIMUNA'S PHOTO
1. Open the website.
2. Tap "Choose a photo" and select the photo.
3. To add more memories, tap "Add photos".
Photos and journal notes are stored in that browser on that device. They are not uploaded or automatically shared with Maimuna.

PUBLISH IT AND GET A SHAREABLE LINK
1. Create/sign in to a GitHub account.
2. Create a new public repository named maimuna-and-ebrima.
3. Upload all files in this folder (not the ZIP itself) to the repository's main/root folder.
4. Open Settings > Pages.
5. Under "Build and deployment", choose "Deploy from a branch", select "main" and "/ (root)", then Save.
6. After GitHub Pages publishes it, your link will look like:
   https://YOUR-USERNAME.github.io/maimuna-and-ebrima/
   Replace YOUR-USERNAME with your GitHub username.

ANDROID INSTALL
Open the published link in Chrome on Android, tap the three-dot menu, then "Add to Home screen" or "Install app" if shown.

IMPORTANT LIMITATIONS
This is a static website. It does not provide real private messaging, shared accounts, server-backed voice messages, or a response inbox. The notes/photos are local to the browser and are not sent to another person. A real shared messaging feature needs a secure backend and user consent.
